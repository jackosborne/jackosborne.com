Back in August I posted about [a UX issue within wordpress when saving a post or page](/blog/2010/08/a-wordpress-ux-problem/). Shortly after posting this someone from the core team got in touch to say that this is something which had been discussed for version 2.8 but for some reason it did not make it into the final release.

However, after upgrading to 3.1 last night I noticed that the issue I wrote about had now been resolved.

Previously when you clicked save draft the spinner would appear next to the publish button which would set your heart racing as you thought you had clicked the wrong button and therefore accidently sending a potentially unfinished blog post out to all of your RSS subscribers. However, since the latest update the spinner now appears correctly; next to the save draft button.

It's nice to know that the wordpress team listen to what others have to say about their product and that they try to implement all legitimate concerns or ideas which could further enhance the product. If you have an idea which you think would improve wordpress then why not write about it, explaining why you think it would act as an improvement.
